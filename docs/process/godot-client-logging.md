# Godot Client Logging

## Reconnect diagnostics

`client/scripts/connection.gd` は、サーバーが停止していても接続を維持する
ため、2秒間隔の再接続を続ける。再接続の応答性とログ量は別の責務として扱う。

- 接続試行は2秒間隔のまま維持する
- 接続試行ログと即時接続失敗の警告は、最初の1回と30秒ごとの要約だけ出す
- 接続成功時は再接続の試行カウンタをリセットする
- 接続成功・切断・プロトコルエラーなど、再接続以外の異常は従来どおり記録する

Godotのエンジンログ自体には、このプロジェクトから設定できるローテーションや
最大サイズの仕組みがない。したがって、クライアント側で再接続ループのログ量を
制限することが第一の防波堤になる。既に肥大化した `godot.log` を削除または退避
するときは、Godotを終了してから行う。

接続失敗が続く場合のログは、通常の失敗原因調査に必要な情報を残しつつ、1日中
再接続しても接続試行だけでログを無制限に増やさないことを保証する。
