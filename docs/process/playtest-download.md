# Dawn Playtest (Windows x86_64)

1. Download the `windows-x86_64.zip` asset from GitHub Releases (not the source archive).
2. Extract the entire ZIP to a writable folder. Keep the EXE, PCK and DLL together.
3. Run `Dawn.exe`. Godot, Rust and the development tools are not required.
4. Enter the server URL and invite code provided by the organizer, then select Connect.

Requirements: Windows 10/11 x86_64, a Vulkan-capable GPU/driver supporting Godot
Forward+, and an internet connection. Other platforms and older GPUs are not
validated. This build is unsigned: Windows may show a publisher warning. Only
run builds obtained from the official Dawn repository; do not disable antivirus.

This is an experimental playtest, not a stable release. Servers may sleep or
restart, data may be reset, and client/server versions must match. Invite codes
are shared privately and are not included in the download.

For bugs, report the version/commit from BUILD.txt, reproduction steps and GPU
model. Do not post invite codes or resume tickets. Third-party license texts
and source links are included alongside the executable.
